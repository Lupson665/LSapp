# LSapp - connector with MSFS2024

Free home cockpit software for Microsoft Flight Simulator, by Lupson Simulation.

LSapp connects cockpit boards running the LSboard firmware to the simulator: buttons, switches, lamps, potentiometers, encoders, displays and motors. Each board is set up in the built-in board configurator, and every aircraft has its own set of assignments.

## Download

Installers are published on the [Releases](https://github.com/Lupson665/LSapp/releases) page.

Current test version: **0.000.7** (pre-release, for testing). Download `LSapp_Setup_0.000.7.exe` from that release and run it.

## Updates

From version 0.000.3 on, LSapp checks this repository for updates when it starts, and from the tray icon menu ("Check for updates..."). Only versions the author has approved here are offered. Your own settings are kept during an update.
