# LSapp

Free home cockpit software for Microsoft Flight Simulator, by Lupson Simulation.

LSapp connects cockpit boards running the LSboard firmware to the simulator: buttons, switches, lamps, potentiometers, encoders, displays and motors. Each board is set up in the built-in board configurator, and every aircraft has its own set of assignments.

Installers are published on the [Releases](https://github.com/Lupson665/LSapp/releases) page. No release has been published here yet.
